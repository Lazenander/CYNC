# CYNC

An experimental programming language and compiler written in Rust.

**Under construction.** The compiler is incomplete and does not currently build.

## Structure

| Path | Contents |
| --- | --- |
| `src/compiler/lexer/` | Tokenisation |
| `src/compiler/parser/` | Hand-written parser |
| `src/compiler/analyzer/` | Module resolution and type analysis |
| `src/compiler/codegen/` | Code generation placeholder |
| `src/pipeline/` | Package dependencies and compiler driver |
| `src/cli/` | Command-line interface |
| `src/runtime/` | Runtime placeholder |
| `examples/` | Example programs and package manifests |
| `preludes/std/` | Standard definitions |
